# 需求管理范围

系统管理需求内容、评审、不可变正式版本、受控变更、关系、标签、评论和审计。单项目是运行边界；不引入 Project、Sprint、Task、TestCase、Organization、Workspace。

正式内容为标题、描述、层级、性质、优先级、来源、理由、验收标准。负责人、标签和当前关系作为管理信息，只留审计。五种预定义角色按并集合并权限，自我评审限制不被角色覆盖。
